# Kiko Thomas — Portfolio Website

Static portfolio website with Shows, Works, and About pages.

## Preview locally

```sh
python3 -m http.server 8765 --directory dist
```

Open http://localhost:8765. Deploy the `dist/` directory with any static host.

- `dist/assets/`: artwork images and original logo
- `dist/data.js`: artwork metadata
- `dist/app.js`: pages and navigation
- `dist/style.css`: responsive styles
